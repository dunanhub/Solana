# Solana Transaction Analyzer

Простой учебный CLI-проект на Rust. Программа запрашивает сумму перевода и комиссию в SOL, переводит их в lamports (1 SOL = 1 000 000 000 lamports), считает итог и показывает статус транзакции. Некорректный ввод обрабатывается без паники.

## Запуск

```powershell
cd solana_transaction_analyzer
cargo run
```

Введите сумму SOL, затем комиссию SOL. Например: `3` и `0.00007993`.

Это учебный пример с `f64`: результат конвертации округляется до ближайшего lamport.

## Конструкции Rust

- `struct` объединяет данные транзакции.
- `enum` и `match` описывают и обрабатывают допустимый и недопустимый результат.
- `Result` и функции разделяют ввод, конвертацию, проверку и вывод, а также позволяют показать ошибку ввода.
- `&Transaction` и `&TransactionStatus` демонстрируют borrowing: функции читают значения, не забирая ownership.
- `let` и `let mut` показывают неизменяемые и изменяемые переменные.

Эти основы пригодятся при дальнейшем изучении программ Solana: там также нужно описывать данные, проверять условия, работать с lamports, передавать данные по ссылке и обрабатывать ошибки. Здесь нет smart contract, Solana SDK и сторонних crates.
